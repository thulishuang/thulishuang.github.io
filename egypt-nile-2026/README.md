# egypt-nile-2026

2026 年国庆埃及 12 天行程的可交互速查页（像素风路线图 + 逐日安排 + 景点卡片）。

- 线上地址：https://thulishuang.github.io/egypt-nile-2026/
- 数据来源：《2026.10埃及旅行行程.xlsx》行程表与开罗 / 赫尔格达 / 卢克索 / 阿斯旺 / 阿布辛贝五城攻略
- 单文件 `index.html`，无构建、无依赖，直接由 GitHub Pages 托管
- 这是**对外分享版**：不含费用、付款方等隐私内容，行李清单与紧急电话保留
- 页面里的勾选状态只存访客自己的浏览器 `localStorage`，不联网、不收集任何数据

## 本地预览

```bash
python3 -m http.server 8000
# 打开 http://localhost:8000/egypt-nile-2026/
```
