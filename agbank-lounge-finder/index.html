URL 规则：JSON 可以是本项目导出的完整 lounges.json，也可以是记录数组；.xlsx 默认按境外贵宾厅 Excel 解析；包含 <script id="lounge-data"> 的网页会按境内/境外结构化数据解析。

部署到 Cloudflare Pages 时可通过 /proxy?url=... 中转读取跨域资源；部署到 GitHub Pages 时没有后端代理，农行官网 Excel 的实时浏览器加载可能受 CORS 限制，建议使用仓库内的 GitHub Actions 定时生成 data/lounges.json。

也可以把最新 Excel / HTML 转为 data/lounges.json 后重新部署，命令见 README。

部署建议

  • 部署到 GitHub Pages 后可访问 https://thulishuang.github.io/agbank-lounge-finder/；如果用 Cloudflare Pages，也可以获得 *.pages.dev 地址。
  • 如果将来要做微信小程序，建议先用本网页验证数据和交互；小程序需要 AppID、合法 HTTPS 域名配置，成本更高。
  • 贵宾厅权益和开放情况可能临时变化，页面已经保留“以农行掌银 / 权益二维码 / 机场现场为准”的提示。
